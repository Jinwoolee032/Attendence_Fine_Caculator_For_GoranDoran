# 고란도란 출결 및 벌금 관리 프로그램 사용 설명서

본 프로그램은 고란도란 총무부의 출결 관리와 벌금 계산을 자동화하기 위해 제작되었습니다. 복잡한 엑셀 수식 없이 클릭 몇 번으로 출석과 댓글 점수를 관리하고, 엑셀과 동일한 형태의 리포트를 확인할 수 있습니다.

## 1. 프로그램 실행 및 설치
- **`main.exe`** 파일을 더블 클릭하여 실행합니다. (Python 환경이 설치되어 있다면 `python main.py`로 실행 가능)
- 또는 dist 에 있는 `고란도란 출결벌금관리기.exe`를 실행합니다.

- 프로그램이 실행되면 `database.json` 파일에서 기존 데이터를 불러옵니다.

---

## 2. 주요 기능 및 사용법

### 학기 관리 (Semester Management)
프로그램 상단에는 학기별 탭이 있습니다.
-   **학기 추가**: 상단 왼쪽의 **`+`** 버튼을 눌러 새 학기를 추가할 수 있습니다.
    -   **학기 구분**: `정기` (Initial FP: 1.5) 또는 `방중` (Initial FP: 1.0)을 선택합니다.
-   **학기 삭제**: 삭제하려는 학기 탭의 `X` 버튼을 누릅니다. (데이터 보호를 위해 "이해했습니다"를 입력해야 삭제됩니다)

각 학기 내에 **구성원 관리**, **출결 현황**, **벌금 리포트** 3개의 탭이 존재합니다.

### 탭 1: 구성원 관리 (Members)
가장 먼저 동아리 부원들을 등록해야 합니다.
1.  **이름**: 부원의 이름을 입력합니다.
2.  **토론대회 참석 여부**: 체크하면 토론대회 참석 보너스(+1.0 FP)가 적용됩니다.
3.  **추가/삭제**: `추가` 버튼을 눌러 등록하고, 목록에서 선택 후 `삭제` 버튼으로 제거할 수 있습니다.

### 탭 2: 출결 현황 (Attendance)
세션을 추가하고 각 부원의 출결 상태를 기록하는 곳입니다.

#### 1단계: 세션 추가하기
화면 상단의 설정 패널을 이용해 세션을 만듭니다.
-   **날짜**: 달력을 눌러 날짜를 선택하세요.
-   **활동 종류** (중요!):
    -   **출석 (Attendance)**: 실제 모임 출석 여부를 체크합니다.
    -   **댓글 (Comment)**: 카페 댓글 작성 여부를 체크합니다.
-   **제목**: 세션의 이름(예: 9/23 정규세션)이나 댓글 주제(예: 1발제)를 입력합니다.
-   `세션 추가` 버튼을 누르면 표에 새로운 열(Column)이 생성됩니다.

#### 2단계: 출결/댓글 체크하기
표의 각 칸(Cell)을 클릭하여 상태를 변경합니다.
-   **출석 세션**:
    -   `출석`, `결석`, `지각`, `사유서 지각` 등을 선택합니다.
    -   **지각**: 자동으로 **지각 시간(분)**을 묻는 창이 뜹니다. 시간을 입력하면 벌금이 자동 계산됩니다.
    -   **사유서 지각**: FP 0.5개를 소모하여 벌금을 면제받습니다 (FP < 0.5일 경우 3000원 벌금).
    -   **F**: FP 1.0개를 소모하여 벌금을 면제받습니다 (FP 부족 시 부분 차감 또는 전체 6000원 벌금).
    -   **A, B, C...**: 특별 면제 사유 (벌금 면제).
-   **댓글 세션**:
    -   `작성`, `미작성`, `지각` 중 선택합니다.
    -   **미작성**: 벌금 2000원 (누적 2회까지는 경고, **2회 초과 시** 전체 미작성 벌금 부과).
    -   **지각**: 벌금 1000원.
-   ***중요***: 출결/댓글 체크 드롭박스는 마우스 스크롤 또는 터치패드의 슬라이딩으로도 변경되기에 오작동하지 않도록 유의하셔야 합니다.

**세션 삭제**: 표의 헤더(날짜/제목 부분)를 우클릭하거나, 셀을 선택한 후 `선택한 세션 삭제` 버튼을 눌러 삭제할 수 있습니다.

### 탭 3: 벌금 리포트 (Reports)
현재까지의 기록을 바탕으로 벌금 현황을 봅니다.

1.  **리포트 생성**: `현재 상태로 리포트 생성` 버튼을 누릅니다.
2.  **옵션 설정**:
    -   **프리패스 공제 여부**: 체크하면, 결석 등으로 발생한 벌금을 남은 프리패스로 차감하여 **실납부액**을 계산합니다.
3.  **결과 확인**: 새 탭이 열리며 엑셀과 동일한 형식의 표가 나타납니다.
    -   **내용**: 잔여 FP, 댓글 불참 점수, 댓글/출석 벌금 내역 등.
    -   **Outdated**: 모 데이터가 변경되면 리포트 탭 제목에 `(Outdated)` 표시가 뜹니다. 최신 데이터로 다시 생성해주세요.
4.  **엑셀 저장**: `이 리포트 Excel 내보내기` 버튼을 눌러 `.xlsx` 파일로 저장할 수 있습니다.
    -   파일 이름 예시: `리포트_공제O(날짜_시간).xlsx`

## 3. 자주 묻는 질문 (FAQ)

**Q. 데이터를 따로 저장해야 하나요?**
A. 아니요, 변경 시마다 `database.json` 파일에 **자동으로 저장**됩니다.

**Q. 지각 시간을 잘못 입력했어요.**
A. 해당 칸을 눌러 다른 상태로 변경했다가, 다시 `지각`을 선택하면 시간을 새로 입력할 수 있습니다.

**Q. 같은 날짜에 "출석"과 "댓글"을 둘 다 만들 수 있나요?**
A. 네, 가능합니다. 날짜가 같아도 활동 종류가 다르면 별도의 세션으로 관리됩니다.

**Q. 엑셀 파일이 안 열려요.**
A. 엑셀 파일이 이미 열려 있는 상태에서 덮어쓰기를 시도하면 에러가 날 수 있습니다. 엑셀을 끄고 다시 저장해 주세요.

**Q. 회칙 변경 등의 사유로 다른 규칙을 적용하고 싶어요.**
A. 본 프로그램은 `PyInstaller`를 통해 패키징되어 배포될 예정입니다. 규칙을 변경하려면 소스 코드를 직접 수정하고 다시 빌드해야 합니다.

1.  **소스 코드 다운로드**: `https://github.com/Jinwoolee032/Attendence_Fine_Caculator_For_GoranDoran.git` (GitHub Repository)
2.  **수정할 파일**:
    -   `src/calc_engine.py`: 벌금 금액(기본 6000원 등), 지각비 계산 방식, 댓글 벌금 기준(2회 초과 등) 등 핵심 로직이 들어있습니다.
    -   `src/models.py`: 출석 상태(출석, 지각, F 등)의 종류를 변경할 때 수정합니다.
3.  **빌드**: 수정 후 `pyinstaller`를 이용해 실행 파일(`main.exe`)을 다시 생성하여 배포하세요.
